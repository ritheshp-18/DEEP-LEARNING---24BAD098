# Comparative Study of Activation Functions and Optimization Algorithms

## Overview
This repository contains the implementation for comparing Sigmoid, Tanh,
and ReLU activation functions, and SGD, Momentum, RMSProp, and Adam
optimizers on an ANN trained on the MNIST dataset.

## Contents
- `EX_2_Activation_Functions.ipynb` — full notebook with Parts A, B, C
- `activation_model.h5` — trained model file

## Tools Used
- Python, TensorFlow/Keras
- Google Colab, Google Drive
- Git & GitHub
